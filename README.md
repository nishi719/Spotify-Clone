# 🎧 Spotify Clone

A responsive and feature-rich web application built with **React** and **Vite**. The project replicates the core functionalities and user interface of Spotify, enabling users to explore a simulated music streaming platform. This project is designed using modern development practices, including component-based architecture and Tailwind CSS for styling.

---

## 📖 Overview

The **Spotify Clone** project demonstrates practical web development skills using React and Vite. The application mimics the key features of Spotify while providing an interactive and dynamic user interface. It is structured with reusable components and styled for a seamless user experience.

---

## 🚀 Features

1. **Responsive Design**: 
   - Optimized for various screen sizes, ensuring a consistent experience across desktop, tablet, and mobile devices.
   
2. **React Component Architecture**: 
   - Modular design with reusable components such as `Navbar`, `Player`, `Sidebar`, and `SongItem`.

3. **Music Playback Controls**: 
   - Functionalities for play, pause, skip forward, and skip backward.
   - Progress bar indicating the current playback time.

4. **Dynamic Song and Album Display**: 
   - Showcases tracks and albums with appropriate visuals like album art.

5. **Interactive Sidebar**: 
   - Easily navigate between different sections of the application.

6. **Context API for State Management**: 
   - Utilized for managing global states like playback status.

7. **Tailwind CSS Styling**: 
   - Modern styling for visually appealing and consistent UI.

8. **Custom Hooks and Utility Functions**:
   - Modular functions for clean and efficient code management.

---

## 🛠️ Technologies Used

- **React**: For building the user interface with components.
- **Vite**: For fast and efficient bundling and development.
- **CSS3**: For styling and layout.
- **JavaScript (ES6)**: For implementing logic and interactivity.
