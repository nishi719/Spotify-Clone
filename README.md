# 🎧 Spotify Clone

A responsive web application built with React and Vite that emulates the core features and user interface of Spotify. This project demonstrates practical front-end development using modern React practices and component-based architecture.

## 🚀 Features

- **Responsive Design**: Optimized for viewing across various devices.
- **React Component Architecture**: Modular and reusable components built using `.jsx`.
- **Music Playback Controls**: Includes play, pause, next, and previous functionalities.
- **Dynamic Progress Bar**: Visual representation of song progress.
- **Song List & Album Art Display**: Showcases available tracks with corresponding album artwork.
- **Interactive UI Elements**: Hover effects and animations for an enhanced user experience.

## 🛠️ Technologies Used

- **React**: For building the user interface with components.
- **Vite**: For fast and efficient bundling and development.
- **CSS3**: For styling and layout.
- **JavaScript (ES6)**: For implementing logic and interactivity.
